# 对比与评分

## 对比目标

对比功能要帮助用户回答一个问题：在指定时间窗内，哪个候选地点最值得去拍银河，以及为什么。

## 输入

- 地点 id 列表，建议 2 到 20 个。
- 出发点坐标，可为空。
- 本地日期。
- 起止小时，允许跨午夜。
- 评分权重，可为空。

## 输出

- 每个地点的摘要：最佳小时、总分、距离、推荐状态、主要原因。
- 每个地点逐小时详情：天气、天文、光污染、分项评分、扣分解释。
- 全局最佳地点 id。

## 默认总分

```text
total_score = light_score * 0.25
            + weather_score * 0.40
            + astronomy_score * 0.25
            + distance_score * 0.10
```

默认权重：

- 光污染：0.25
- 天气：0.40
- 天文窗口：0.25
- 距离：0.10

权重总和必须等于 1。用户自定义权重应保存到对比会话。

## 天气分

```text
weather_score = 100
  - cloud_penalty
  - precipitation_penalty
  - visibility_penalty
  - wind_penalty
  - humidity_penalty
```

建议规则：

- 云量是最大影响项，高云和中云对银河清晰度影响明显。
- 降水概率和降水量任一明显升高，都应强扣分。
- 能见度低于 10 km 标记为明显风险。
- 风速大于 25 km/h 开始扣分，阵风大于 40 km/h 标记风险。
- 湿度大于 85% 或温度接近露点时提示结露风险。

硬性标记：

- `precipitation_mm > 0.5`：默认 `not_recommended`。
- `cloud_cover_pct > 70 && cloud_cover_high_pct > 50`：默认 `not_recommended`。
- 关键字段缺失：不直接扣满分，但降低 confidence。

## 光污染分 ✅ 已实现（M4）

如果有 SQM：

| SQM | 分数 |
| --- | --- |
| `>= 21.75` | 100 |
| `21.3 - 21.75` | 85 |
| `20.8 - 21.3` | 70 |
| `20.0 - 20.8` | 50 |
| `19.0 - 20.0` | 30 |
| `< 19.0` | 10 |

如果没有 SQM，使用 darkness_class（1-5）：

| darkness_class | 辐亮度范围 (nW·cm⁻²·sr⁻¹) | 分数 | 标签 |
| --- | --- | --- | --- |
| 1 | `<= 0.5` | 100 | 极暗 |
| 2 | `0.5 - 2` | 85 | 暗 |
| 3 | `2 - 5` | 70 | 中等 |
| 4 | `5 - 15` | 50 | 较亮 |
| 5 | `> 15` | 10 | 明亮 |

禁止事项：

- Bortle 始终标记为 `estimate`，不输出精确 Bortle 等级。
- `darkness_class` 由 VIIRS 辐亮度阈值生成，不代表实测天空亮度。
- 无任何光污染数据时，分数为 0，标签为"无数据"。

## 天文分 ✅ 已实现（M3）

```text
astronomy_score = night_score - moon_penalty + milky_way_bonus
```

规则：

- 非天文夜：`night_score` 最高 40。
- 天文夜：`night_score = 80`。
- 月亮在地平线以下：`moon_penalty = 0`。
- 月亮在地平线上且照亮比例高：按高度和照亮比例扣 0 到 40。
- 银河核心高度大于 10 度：加 10。
- 银河核心高度大于 20 度：加 20。

## 距离分

MVP 按直线距离：

| 距离 | 分数 |
| --- | --- |
| `<= 30 km` | 100 |
| `30 - 100 km` | 线性下降到 70 |
| `100 - 250 km` | 线性下降到 40 |
| `> 250 km` | 20 |

## 推荐状态

- `recommended`：总分高且无硬性风险。
- `watch`：有风险但仍可能可拍。
- `not_recommended`：云、雨、非天文夜或月光风险明显。
- `unknown`：关键数据不足。

## 解释原因

每个地点和小时最多返回 3 到 5 条主要原因。原因应短、可读、可追溯。

示例：

```json
{
  "totalScore": 86,
  "recommendation": "recommended",
  "topReasons": ["云量低", "月亮已落", "光污染低"],
  "risks": ["距离较远"]
}
```

## M2 评分说明（当前实现）

M2 里程碑仅使用天气和距离两项评分，光污染和天文窗口暂不参与。M3 已接入天文评分。

```text
M2_total_score = weather_score * 0.8 + distance_score * 0.2
```

- 天气分：按云量、降水、能见度、风速、湿度计算。
- 距离分：按 Haversine 直线距离查表。
- 光污染分：M4 接入后参与。
- 天文分：✅ M3 已接入。

## 排序规则

- 默认按地点最佳小时的 `total_score` 降序。
- 如果分数相同，优先距离近。
- 如果天气 confidence 低，排序时可降低 5 到 10 分或标记 `unknown`。
