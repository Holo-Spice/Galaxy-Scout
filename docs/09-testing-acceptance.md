# 测试与验收

## 单元测试

必须覆盖：

- Haversine 距离计算。
- 跨午夜时间窗，如 20:00 到次日 05:00。
- 天气评分扣分逻辑。
- 月亮在地平线下不扣月光分。
- 只有 VIIRS 数据时不输出实测 Bortle。
- 标签 trim、去重和空值拒绝。

## 集成测试

必须覆盖：

- 多地点天气请求合并。
- Open-Meteo 多坐标响应能正确映射到地点。
- 缓存命中时不重复请求 provider。
- 地点坐标变更后相关缓存失效。
- 图片上传后生成数据库记录和缩略图任务。

## E2E 测试

必须覆盖：

- 新增地点 -> 收藏 -> 加入对比 -> 查看最佳小时。
- 地图点击创建地点。
- 上传机位图片并设为封面。
- 移动端打开对比页，小时数据可横向滚动。

## 数据质量检查

- 光污染数据导入后抽样检查城市和暗空区域。
- 天气字段缺失时页面显示 `数据不足`，不崩溃。
- 所有外部数据展示 source 和更新时间。
- 评分解释能追溯到原始分项。

## MVP 验收标准

- 至少能保存 20 个地点。
- 同时对比 10 个地点时页面可交互。
- 天气数据能展示未来 7 天逐小时字段。
- 光污染字段能显示数据源、年份和可信度。
- 评分解释可读，能说明推荐或不推荐原因。
- 手机端能查看地点、对比结果和图片。
- 地图页面显示 attribution。
