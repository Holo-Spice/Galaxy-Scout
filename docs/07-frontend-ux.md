# 前端与交互

## 页面

| 页面 | 路径 | 目标 |
| --- | --- | --- |
| 仪表盘 | `/` | 今日候选、最近收藏、快速对比 |
| 地点列表 | `/locations` | 管理地点、收藏、标签 |
| 地点详情 | `/locations/:id` | 机位图片、备注、光污染、历史信息 |
| 地图选点 | `/map` | 地图点选、光污染图层、保存地点 |
| 多地点对比 | `/compare` | 核心决策页面 |
| 设置 | `/settings` | 出发点、单位、评分权重、数据源状态 |

## 动画系统

动画库：

- Framer Motion：页面过渡、组件动画。
- React Three Fiber (R3F)：3D 星空背景。

动画模式：

- 页面过渡：AnimatePresence fade。
- 卡片交错揭示：stagger reveal。
- 数字滚动：AnimatedNumber。
- 3D 倾斜：TiltCard。
- 3D 星空：R3F starfield。

降级策略：

- JS 层：useReducedMotion hook 检测用户偏好。
- CSS 层：global override 作为安全网。
- 动画变体统一定义在 `src/lib/animation.ts`。

## 组件结构

共享组件：

- StatusBadge：状态徽章。
- LocationHero：英雄横幅。
- StatCardGrid：统计卡片网格。
- TagList：标签列表。
- AnimatedNumber：数字滚动动画。
- TiltCard：3D 倾斜卡片。
- AnimatedMain：页面过渡容器。

地图子组件：

- MapMarker：地图标记。
- LayerToggle：图层开关。
- LocationPanel：地点面板。

## 多地点对比 UI

核心信息：

- 地点名称、标签、封面图。
- 最佳小时、总分、推荐状态。
- 距离和距离模式。
- 光污染来源、年份、可信度。
- 逐小时云量、降水、月亮、银河窗口。
- 扣分原因和风险标签。

交互：

- 支持选择 2 到 20 个地点。
- 支持按综合分、距离、云量、光污染排序。
- 支持展开地点查看小时详情。
- 支持切换目标日期和时间窗。

## 地图 UI

要求：

- 地图点击可创建候选地点。
- 支持地点 marker、出发点 marker、距离圈。
- 可叠加光污染图层。
- attribution 必须可见。
- 移动端底部抽屉不能遮挡 attribution。

## 地点详情 UI

展示：

- 封面图和图片列表。
- 经纬度、海拔、区域、timezone。
- 访问说明、前景说明、安全说明。
- 光污染摘要。
- 最近天气或最近对比结果。

编辑：

- 经纬度修改前提示会导致缓存失效。
- 标签输入 trim 并去重。
- 图片可设置封面、隐藏、软删除。

## 状态文案

推荐状态：

- `recommended`：推荐。
- `watch`：可关注，有风险。
- `not_recommended`：不推荐。
- `unknown`：数据不足。

风险标签：

- `高云偏多`
- `有降水风险`
- `月光干扰`
- `非天文夜`
- `光污染偏高`
- `距离较远`
- `数据过期`

## 移动端原则

- 地点卡片优先于大表格。
- 小时数据允许横向滚动。
- 地图和对比页面避免过深层级。
- 关键状态不能只靠颜色表达，必须有文字。

## 视觉原则

- 信息密度高，但决策状态醒目。
- 色彩用于风险分级，但文本解释必须同步存在。
- 不做花哨动效，优先加载速度和户外可读性。
